# Прогнозирование продаж на 2017 год

## Цель проекта

Цель проекта — построить модель прогнозирования ежедневных продаж на 2017 год на основе исторических данных за 2013–2016 годы.

В проекте сравниваются несколько подходов к прогнозированию:

- Baseline 1 — прогноз на основе продаж за аналогичную дату прошлого года;
- Baseline 2 — прогноз прошлого года с корректировкой на средний темп роста продаж;
- CatBoost — модель машинного обучения с календарными, лаговыми и скользящими признаками.

Качество прогнозов оценивается по метрикам MAE, RMSE и MAPE.


## Данные

В проекте используется датасет с ежедневными продажами товаров по магазинам за период с 2013 по 2017 год.

Основные характеристики данных:

- 10 магазинов;
- 50 товаров;
- ежедневная детализация продаж;
- период данных: 2013–2017 годы.

Основные поля датасета:

- `date` — дата;
- `store` — идентификатор магазина;
- `item` — идентификатор товара;
- `sales` — количество продаж.

Для построения моделей использовались данные за 2013–2016 годы.

Данные за 2017 год не использовались при обучении и были оставлены для финальной проверки качества прогноза.


## Исследовательский анализ данных

Перед построением моделей был проведён анализ исторических продаж.

Основные наблюдения:

- общий объём продаж рос с 2013 по 2016 год;
- в данных выражена сезонность: продажи растут к лету и достигают пика примерно в июле;
- после летнего пика наблюдается снижение продаж;
- магазины отличаются по общему объёму продаж, но имеют схожую сезонную динамику;
- товары также различаются по уровню спроса;
- продажи заметно зависят от дня недели: минимальные значения наблюдаются в начале недели, максимальные — ближе к выходным;
- крупные значения продаж в летние месяцы были проверены и не рассматривались как ошибочные выбросы.
