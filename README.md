# Прогнозирование продаж на 2017 год

## Цель проекта

Цель проекта — построить модель прогнозирования ежедневных продаж на 2017 год на основе исторических данных за 2013–2016 годы.

В проекте сравниваются несколько подходов к прогнозированию:

- Baseline 1 — прогноз на основе продаж за аналогичную дату прошлого года;
- Baseline 2 — прогноз прошлого года с корректировкой на средний темп роста продаж;
- CatBoost — модель машинного обучения с календарными, лаговыми и скользящими признаками.

Качество прогнозов оценивается по метрикам MAE, RMSE и MAPE.


## Данные

В проекте используется датасет с ежедневными продажами товаров по магазинам за период с 2013 по 2017 год.

Основные характеристики данных:

- 10 магазинов;
- 50 товаров;
- ежедневная детализация продаж;
- период данных: 2013–2017 годы.

Основные поля датасета:

- `date` — дата;
- `store` — идентификатор магазина;
- `item` — идентификатор товара;
- `sales` — количество продаж.

Для построения моделей использовались данные за 2013–2016 годы.

Данные за 2017 год не использовались при обучении и были оставлены для финальной проверки качества прогноза.


## Исследовательский анализ данных

Перед построением моделей был проведён анализ исторических продаж.

Основные наблюдения:

- общий объём продаж рос с 2013 по 2016 год;
- в данных выражена сезонность: продажи растут к лету и достигают пика примерно в июле;
- после летнего пика наблюдается снижение продаж;
- магазины отличаются по общему объёму продаж, но имеют схожую сезонную динамику;
- товары также различаются по уровню спроса;
- продажи заметно зависят от дня недели: минимальные значения наблюдаются в начале недели, максимальные — ближе к выходным;
- крупные значения продаж в летние месяцы были проверены и не рассматривались как ошибочные выбросы.


## Baseline-модели

Для сравнения качества прогноза были построены две базовые модели.

### Baseline 1

Прогноз на 2017 год строится на основе продаж за аналогичную календарную дату 2016 года.

Этот подход используется как простая отправная точка для оценки качества более сложной модели.

### Baseline 2

К прогнозу Baseline 1 дополнительно применяется средний темп роста продаж для каждой пары `store` + `item`, рассчитанный по историческим данным.

Таким образом, модель учитывает не только сезонность прошлого года, но и общий тренд роста продаж.


## Модель CatBoost

Для построения основного прогноза использовалась модель `CatBoostRegressor`.

В модель были переданы следующие признаки:

- `store` — идентификатор магазина;
- `item` — идентификатор товара;
- `day_of_week` — день недели;
- `month` — месяц;
- `year` — год;
- `week_of_year` — номер недели в году;
- продажи 1 день назад;
- продажи 7 дней назад;
- продажи 28 дней назад;
- средние продажи за предыдущие 7 дней;
- средние продажи за предыдущие 28 дней.

Признаки `store` и `item` использовались как категориальные.

Для подбора параметров модель сначала проверялась на 2016 году, после чего финальная версия была обучена на всех данных за 2013–2016 годы.

## Валидация и подбор модели

Для корректной оценки качества данные были разделены по времени:

- 2013–2015 годы — обучение модели;
- 2016 год — валидация.

Такой подход позволяет проверить качество прогноза на будущем периоде, не перемешивая данные случайным образом.

На валидации сравнивались baseline-модель и несколько вариантов CatBoost.

Лучший результат CatBoost на 2016 году:

- MAE ≈ 6.02;
- RMSE ≈ 7.85;
- MAPE ≈ 12.64%.

Для сравнения Baseline 1 на 2016 году показал:

- MAE ≈ 12.59;
- RMSE ≈ 16.25;
- MAPE ≈ 24.25%.

После проверки на 2016 году финальная модель была обучена на всех данных за 2013–2016 годы.


## Прогноз на 2017 год

После выбора финальной версии CatBoost модель была обучена на всех данных за 2013–2016 годы.

Прогноз на 2017 год строился рекурсивно, день за днём.

Для каждого нового дня рассчитывались:

- продажи 1 день назад;
- продажи 7 дней назад;
- продажи 28 дней назад;
- средние продажи за предыдущие 7 дней;
- средние продажи за предыдущие 28 дней.

После получения прогноза за очередной день это значение добавлялось в историю и использовалось для расчёта признаков следующих дней.

Таким образом, фактические продажи 2017 года не использовались при построении прогноза.

После завершения прогнозирования результаты были сравнены с реальными продажами за 2017 год.


## Результаты

После построения прогноза на 2017 год все модели были сравнены по метрикам MAE, RMSE и MAPE.

| Метрика | Baseline 1 | Baseline 2 | CatBoost |
|---|---:|---:|---:|
| MAE | 11.57 | 11.67 | **6.26** |
| RMSE | 15.43 | 16.34 | **8.23** |
| MAPE | 22.65% | 24.18% | **12.38%** |

CatBoost показал лучший результат по всем трём метрикам.

По сравнению с лучшей baseline-моделью MAPE снизился примерно с 22.65% до 12.38%.

Это показывает, что использование календарных, лаговых и скользящих признаков заметно улучшило качество прогноза.
